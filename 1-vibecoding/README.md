# Vibecoding workshop

Build a small app by prompting GitHub Copilot in agent mode. Do not write code yourself: describe what you want, look at the result, and prompt again.

## Pick an idea

Use one of the ideas in `suggestions/`, or bring your own. Keep your first prompt short; you will need it again later.

- [Catan helper](suggestions/catan-helper.md)
- [Meeting cost ticker](suggestions/meeting-cost-ticker.md)
- [Team lunch picker](suggestions/team-lunch-picker.md)

## How to work

1. Open this folder in VS Code.
2. Open Copilot Chat and switch to agent mode.
3. Write your first prompt, and save it somewhere: you will use the exact same prompt in the next round.
4. Run what it builds, try it, prompt again.

## Rules

- Fictional data only. No customer data and no personal data in a prompt.
- Help each other. Look at what your neighbour is building.

## Afterwards

Be ready to answer:

- What did you want to build?
- What did you prompt, initially?
- How much back and forth did it take?
- Did you get what you wanted?
